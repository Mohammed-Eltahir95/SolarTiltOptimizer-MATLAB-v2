# Legacy reference

The original `tilt_optimization_4locations_allinone.m` is retained here as a
read-only regression reference. It is not called by the modular application.
The source bundle contained Wadi Halfa, Khartoum, Port Sudan, and **Kadugli**
workbooks; the requested portfolio demonstration instead configures Dongola.
No legacy workbook is redistributed here because its publication rights and
PVGIS provenance metadata were not established.
